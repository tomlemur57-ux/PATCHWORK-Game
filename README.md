# PATCHWORK

A native Windows game about connecting rooms by moving their windows.

## Workspace

This is the game repository. The code workshop, setup tools and lesson progress live outside it.
No game implementation has been created by the cleanup. Build the first room in chapter 01, then keep extending the same files.

## Open the workshop

Run this in PowerShell:

```powershell
node "$env:LOCALAPPDATA\PATCHWORK-Workshop\workshop.cjs" start
```

The server runs on 127.0.0.1 only. Use its Stop server button to stop it. Start it again after a restart.

## Save your work

Save edited files, review and stage the changes in VS Code Source Control, then Commit & Push.
Do not commit credentials, local logs, or the workshop. GitHub history and Hackatime editing records are separate.

## Tracking

Open the workshop's Tracking page. An accepted key is not proof of received editing activity.
Only the editor plugin sends coding activity; reading lessons does not generate it.

## First build

This workshop teaches C/Win32 (not Godot). Build-support files are introduced explicitly in the browser, not installed in the project automatically.
